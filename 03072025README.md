## 📋 **Overview**

This is a setup guide for **FSBook Guacamole**, which is a web-based remote desktop system that allows developers to access Ubuntu desktop environments through their web browsers. It's designed for organizations to provide consistent development environments to their team members.

## 🏗️ **System Architecture**

The system consists of:

### **Core Components:**
1. **Apache Guacamole** - Web-based remote desktop gateway
2. **MySQL Database** - Stores user credentials and connection configurations  
3. **Ubuntu RDP Containers** - Individual developer workspaces with desktop environments
4. **XFCE Desktop Environment** - Lightweight GUI for each container

### **Key Features:**
- **Web Access**: Developers access desktops through http://localhost:8080/guacamole
- **Container Isolation**: Each developer gets their own Ubuntu container
- **Persistent Storage**: Developer data is preserved between sessions
- **Pre-configured Tools**: Each container includes development tools

## 🚀 **Main Setup Process**

### **One-Command Setup:**
```bash
chmod +x *.sh && ./complete-fsbook-setup.sh
```

This single command does everything:
1. **Downloads Guacamole Database Schema** - Gets the proper database structure
2. **Builds Ubuntu RDP Containers** - Creates the developer environments
3. **Sets up MySQL Database** - With complete schema and admin user
4. **Configures Admin User** - Default login `guacadmin`/`guacadmin`
5. **Creates Pre-configured RDP Connections** - Ready-to-use developer access
6. **Verifies System Health** - Ensures everything is working

## 👥 **User Management**

### **Pre-configured Developers:**
- **John**: Container `fsbook-dev-john`, RDP port 3391
- **Jane**: Container `fsbook-dev-jane`, RDP port 3392
- Both use username/password: `john`/`developer123` and `jane`/`developer123`

### **Adding New Developers:**
```bash
./add-developer.sh alice 3393  # Adds Alice on port 3393
docker-compose up -d dev-alice  # Starts Alice's container
```

1. **Admin runs setup** → System is configured
2. **Developers are added** → Each gets their own container
3. **Users access via web** → http://localhost:8080/guacamole
4. **Choose environment** → dev/qa/prod folders
5. **Connect to container** → Full Ubuntu desktop in browser
6. **Develop & work** → All tools available, work is saved
